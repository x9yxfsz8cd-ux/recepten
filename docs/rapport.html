Wat is dit?

Een persoonlijke receptensite voor Shar & Robin. Statische PWA op GitHub Pages. Geen framework, geen build-stap — vanilla HTML/CSS/JS. Recepten staan in één JSON-bestand. Nieuwe recepten worden via een import-pagina toegevoegd (Claude API vision + URL scraping).

Stack
  • Frontend: Vanilla HTML/CSS/JS, geen framework
  • Hosting: GitHub Pages, branch main, map docs/
  • Data: docs/data/recepten.json — één JSON-array
  • PWA: Service Worker (docs/sw.js), cache-first strategie
  • Fonts: Space Grotesk (koppen), Inter (body), JetBrains Mono (meta/code)
  • Thema: GitHub dark + Apple liquid glass accenten + butter yellow #f0c84a
  • AI import: Claude API (claude-haiku-4-5-20251001), direct vanuit browser

Data model — recepten.json

Elk recept heeft dit schema:

{
  "id": "r001",                        // stabiele string-ID
  "titel": "Pasta al Limone",
  "slug": "pasta-al-limone",
  "beschrijving": "Korte omschrijving.",
  "afbeelding": "https://... of ./img/naam.jpg",
  "bereidingstijd": 25,                // totale tijd in minuten
  "actieve_tijd": 15,                  // optioneel — actief koken
  "passieve_tijd": 10,                 // optioneel — wachten/oven
  "moeilijkheidsgraad": "makkelijk",   // makkelijk / gemiddeld / moeilijk
  "porties": 2,
  "tags": ["vegetarisch", "snel", "Italiaans"],
  "ingredienten": [
    { "naam": "spaghetti", "hoeveelheid": 200, "eenheid": "g" },
    { "naam": "zout",      "hoeveelheid": 0,   "eenheid": "naar smaak" }
  ],
  "stappen": [
    { "nummer": 1, "tekst": "Kook de pasta..." }
  ],
  "voedingswaarden": {
    "kcal": 580, "eiwitten": 18, "koolhydraten": 72, "vetten": 24
  },
  "bron": "https://...",               // originele URL, leeg bij handmatig
  "bron_naam": "Albert Heijn",         // "Handmatig" als het handmatig is
  "bron_type": "url",                  // url / tekst / foto / handmatig
  "datum_toegevoegd": "2026-03-23"
}
Eenheden: g, ml, el, tl, stuks, snuf, naar smaak. Bij naar smaak is hoeveelheid altijd 0.

Geldige tags (vaste lijst): vegetarisch vegan vis vlees snel comfort food Aziatisch Italiaans ontbijt lunch diner snack

localStorage state

KeyWaardeGebruikt in
in_huis JSON array van recept.id strings — recepten waarvoor alle ingrediënten in huis zijn index.html (filter), recept.html (boodschappenlijst)
stappen_<id> JSON array van stapnummers die afgevinkt zijn recept.html
ing_<id> JSON array van ingrediënt-indices die afgevinkt zijn recept.html
claude_api_key Claude API-sleutel (sk-ant-…) — plaintext import.html
De API-sleutel staat in plaintext in localStorage. Dit is bewust gekozen — het is een privésite op een persoonlijk apparaat. Nooit op een gedeeld apparaat gebruiken.

CSS design system

Alle kleur/spacing tokens staan als CSS custom properties op :root in style.css. Licht/donker volgt automatisch prefers-color-scheme.

/* Kernkleuren */
--bg: #0d1117          /* pagina-achtergrond */
--surface: #161b22     /* kaarten */
--surface-2: #1c2128   /* inputs, hover */
--border: rgba(255,255,255,0.08)
--border-2: rgba(255,255,255,0.16)
--text: #e6edf3
--text-muted: #768390
--text-heading: #ffffff
--accent: #f0c84a      /* butter yellow — primaire accentkleur */
--accent-subtle: rgba(240,200,74,0.07)
--accent-border: rgba(240,200,74,0.22)
--glass: rgba(22,27,34,0.65)   /* liquid glass achtergrond */
--glass-border: rgba(255,255,255,0.07)
--glass-hi: rgba(255,255,255,0.12)

Stijlpatroon

  • Kaarten: background: var(--surface); border: 1px solid var(--border); border-radius: 12px — geen blur
  • Liquid glass (ingrediëntenblok, kookmodus-overlay): backdrop-filter: blur(24px) saturate(150%)
  • Knoppen: border + transparante achtergrond, hover via var(--surface-2)
  • Accent-knoppen: background: var(--accent-subtle); border: 1px solid var(--accent-border); color: var(--accent)
  • Grain overlay: body::after met SVG feTurbulence noise
  • Nooit bestaande class- of variabelenamen hernoemen

Functies per pagina

index.html — Homepagina

  • Receptenkaartjes in een responsive grid, geladen uit recepten.json
  • Zoeken op naam en ingrediëntnaam
  • Filteren op tag (uit vaste lijst)
  • Sortering: nieuwste eerst / A–Z / snelste eerst
  • "In huis"-filter: toont alleen recepten waarvan je alle ingrediënten hebt
  • Per kaartje een boodschappicoontje om recept als "in huis" te markeren
  • Skeleton loading animatie tijdens laden
  • Gekleurde placeholder als er geen foto is (vlees=rood, vis=blauw, vegan=groen, etc.)

recept.html — Receptdetail

  • Editoriaal split-header: tekst links, foto rechts (2-koloms grid)
  • Portieschaler (−/+) die alle hoeveelheden herberekent
  • Klik op een hoeveelheid → inline edit → alles schaalt mee
  • Ingrediënten afvinken (persisteert via ing_<id> in localStorage)
  • Stappen afvinken (persisteert via stappen_<id> in localStorage)
  • Kookmodus: fullscreen overlay, stap voor stap, voortgangsbalk, wake lock
  • Timer in kookmodus: parseert Nederlandse tijdsduren uit staptekst, aftellen met pauze/reset, trilt bij nul
  • Boodschappenlijst-knop: kopieert ontbrekende ingrediënten (geschaald) naar klembord
  • Voedingswaarden-blok (indien aanwezig)
  • Bronvermelding met link
  • Printweergave (knoppen en overlay verborgen)

import.html — Recept importeren

  • Drie tabs: URL / Tekst / Foto
  • URL: haalt pagina op via CORS-proxy, extraheert JSON-LD of platte tekst, stuurt naar Claude
  • Tekst: plak recepttekst, WhatsApp-bericht, Instagram-bijschrift, etc.
  • Foto: twee knoppen (camera/galerij), meerdere foto's mogelijk voor recepten op meerdere pagina's, thumbnail strip
  • Claude Haiku extraheert recept als JSON (Nederlandstalig)
  • Preview met portieschaler vóór opslaan
  • Opslaan downloadt bijgewerkte recepten.json — handmatig in repo plaatsen
  • API-sleutel opgeslagen in localStorage, eenmalig invullen
  • URL-parameter: import.html?url=https://...&auto=true voor directe import

Service Worker & PWA

Cache-first strategie. Bij elke update: verhoog CACHE in sw.js, anders krijgen bestaande gebruikers de wijzigingen niet.

// sw.js — huidig versienummer
const CACHE = 'recepten-v12';

Bij elke deploy met wijzigingen in CSS/JS/HTML: bump naar v13, v14, etc.

Timer — tijdsduur parsing

Functie parseerDuur(tekst) in recept.html vangt:

  • 10-12 minuten → bovengrens = 720 seconden
  • 1,5 min → 90 seconden
  • 10 minuten / 10 min / 10 minuut → 600 seconden
  • 30 seconden / 30 sec → 30 seconden

Geen match → geen timer getoond. Timer reset automatisch bij overstap naar volgende stap.

Nieuwe recepten toevoegen

  1. Open /import.html in Safari (desktop of mobiel)
  2. Kies tab: URL (blog/AH/HelloFresh), Tekst (Instagram, WhatsApp) of Foto (kookboek)
  3. Claude Haiku extraheert het recept → preview verschijnt
  4. Pas aan indien nodig (bron, porties)
  5. Klik "Opslaan" → download recepten.json
  6. Vervang docs/data/recepten.json in de repo en push naar main
  7. Foto: sla op in docs/img/ en update afbeelding veld in JSON
De import-pagina staat ook live op de site — handig op mobiel voor kookboekfoto's.

Conventies & valkuilen

  • Hernoem nooit bestaande CSS-klassen of --variabelen
  • Geen externe dependencies toevoegen — alles in vanilla JS/CSS
  • Bij elke deploy met gewijzigde statische bestanden: bump CACHE in sw.js
  • Nieuwe recepten: genereer ID als r + Date.now()
  • Afbeeldingen: sla lokaal op in docs/img/, gebruik relatief pad ./img/naam.jpg
  • Externe afbeeldingURLs (Unsplash, Notion S3) kunnen verlopen — liever lokaal
  • staptekst is platte tekst — geen HTML-tags
  • De in_huis localStorage-key bevat recept-IDs (niet ingrediëntnamen)
  • Claude model voor import: claude-haiku-4-5-20251001
